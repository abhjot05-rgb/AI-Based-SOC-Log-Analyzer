Methodology

Logs are parsed and normalized, then checked by configurable rules (brute force, port scan, suspicious login, account activity, privilege activity, suspicious IP) and by an Isolation Forest anomaly detector. Each finding gets a 0-100 threat score from transparent point components (threat type, attempt volume, event frequency, affected accounts, ML anomaly score, source IP behaviour, escalation indicators), mapped to LOW, MEDIUM, HIGH or CRITICAL. Each alert stores the reason for its severity.

Limitations

  • Rule thresholds and scoring weights are judgement-based settings, not learned from labelled data. No accuracy figure is claimed.
  • ML anomalies are leads, not confirmed attacks. A model trained on a mostly malicious file would find little unusual.
  • "Possible compromise" is a pattern (failures followed by a success from the same IP), not a confirmed breach.
  • This tool only analyzes logs. It has no login, no CSRF protection, and is intended for local use.
